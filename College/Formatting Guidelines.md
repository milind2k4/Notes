# Formatting Standards

1. **Header Numbering:** Do **NOT** use numbered lists or alphabetical lists for Headings H1 through H5. Numbering is only allowed for H6 or body text lists.
    
    - _Wrong:_ `## 1. Introduction` or `## A. Introduction`
        
    - _Right:_ `## Introduction`
        
2. **Bold Syntax:** Punctuation (specifically colons) must be **inside** the bold tags.
    
    - _Wrong:_ `**Definition**:`
        
    - _Right:_ `**Definition:**`
        
3. **Callout Titles:** Do **NOT** include generic prefixes (e.g., "Key Concept", "Tip", "Error") inside the title text. The icon/color already conveys this.
    
    - _Wrong:_ `> [!NOTE] Key Concept: Data vs. Information`
        
    - _Wrong:_ `> [!WARNING] Error: Null Pointer Exception`
        
    - _Right:_ `> [!NOTE] Data vs. Information`
        
    - _Right:_ `> [!WARNING] Null Pointer Exception`
